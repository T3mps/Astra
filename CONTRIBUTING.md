# Contributing to Astra

Astra is an ECS library under the [MIT License](LICENSE), part of the Starworks stack
(it is used by the Arcane engine).

## Sign-off (Developer Certificate of Origin)

Every commit in a pull request carries a sign-off line:

    Signed-off-by: Your Name <you@example.com>

`git commit -s` adds it. The sign-off certifies the
[Developer Certificate of Origin 1.1](https://developercertificate.org/): that
you wrote the change, or otherwise have the right to submit it under this
project's license. Your contribution is licensed under the MIT License, the
same license the project is distributed under.

## Pull requests

- Build and run the tests before opening a pull request (see the README).
- Keep each pull request to one change.
